# Fish Disease Prototype

`fish_disease.onnx` is a two-class MobileNetV3-Small baseline fine-tuned with 30 fish images from the BD Fish & Shrimp Disease Dataset. See `metrics.json` for the split and prototype metrics; six test examples are far too few to establish useful accuracy.
